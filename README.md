# ☀️ SkyCast – Real-Time Weather Dashboard

SkyCast is a modern and responsive weather dashboard that provides real-time weather information for cities around the world. It displays current temperature, weather conditions, humidity, wind speed, precipitation, and other important weather details through a clean and user-friendly interface.

## 🚀 Features

- 🌍 Search weather information for any city worldwide.
- 🌡️ Display current temperature in Celsius.
- ☀️ Show current weather conditions and descriptions.
- 💧 Display humidity levels.
- 🌬️ Show wind speed in km/h.
- 🌧️ Display current precipitation.
- 🌡️ Show feels-like temperature.
- 📍 Display city location details.
- ⚡ Live weather information using the Open-Meteo API.
- 📱 Responsive and modern user interface.

## 🛠️ Technologies Used

- **HTML5** – Website structure.
- **CSS3** – Styling and responsive design.
- **JavaScript** – Functionality and API integration.
- **Open-Meteo API** – Real-time weather data.
- **Google Fonts** – Inter typography.
